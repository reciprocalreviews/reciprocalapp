# Welcome!

This is the repository for the [reciprocal.reviews](https://reciprocal.reviews) web application, which is intended to help make peer review more sustainable.

- If you're interested in contributing, see [our contributor guidelines](CONTRIBUTING.md) to get started.
- If you want to see our progress toward beta, see our [beta roadmap](https://github.com/orgs/reciprocalreviews/projects/1/views/7).
- If you have a question about the project, ask in [Discussions](https://github.com/reciprocalreviews/reciprocalapp/discussions). Answering in the open means the next person with the same question finds it.
- If you found a bug or want a feature, [open an issue](https://github.com/reciprocalreviews/reciprocalapp/issues), where others can see it and add to it.
- If you have a question about a specific journal or conference on Reciprocal Reviews, write to its editors; its page on the platform lists its administrators. The stewards don't run venues and can't answer for them.
- If you need to reach a person about the platform itself, write [stewards@reciprocal.reviews](mailto:stewards@reciprocal.reviews), which reaches all of the [stewards](https://reciprocal.reviews/contact) at once. Use it for a venue proposal, an account or data question, or anything else about Reciprocal Reviews not suited to a public thread.
